# DigitalOcean Flask ADX Business Demo

This Python Flask application simulates a basic web service endpoint, demonstrating how a component of a business intelligence platform like ADX Business might run on a DigitalOcean droplet. It serves a simple HTML page displaying dynamically generated "business metrics" to illustrate data presentation in a cloud environment. This example highlights the foundational web server setup required for such platforms.

## Language

`python`

## How to Run

1. Save the code as `app.py`.
2. Install Flask: `pip install Flask`.
3. Run the application: `python app.py`.
4. Open your web browser and navigate to `http://127.0.0.1:5000`.
